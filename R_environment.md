# R environment

Validated package families used by the public R scripts:

- R >= 4.2
- data.table
- dplyr
- ggplot2
- readr
- stringr
- TwoSampleMR 0.7.9 for the SPI1 sensitivity branch

The public repository contains no lockfile because several workflows depend on project-local GEO and eQTL inputs that are intentionally excluded. Record `sessionInfo()` and the exact input checksums when rerunning a branch.
