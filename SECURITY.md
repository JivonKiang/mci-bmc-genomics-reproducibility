# Security and sensitive-data reporting

Do not open a public GitHub issue containing credentials, private data,
sample-level records, subject-level records, controlled-access data or private
correspondence.

If you find a credential exposure or a sensitive-data problem, contact the
maintainer through the public profile at
https://github.com/JivonKiang and provide only the minimum necessary detail.
Do not upload the affected data or secret to an issue or pull request.

This repository is a public research-code release. It is not a clinical
decision-support system and should not be used to make patient-care decisions.
