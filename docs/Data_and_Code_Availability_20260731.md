# Data and code availability

Prepared: 31 July 2026

The public code and aggregate result tables for this study are available at https://github.com/JivonKiang/mci-bmc-genomics-reproducibility. The repository contains selected analysis scripts, aggregate figure-source tables, mapping audits and evidence-unit summaries.

All reused human datasets are identified by their original GEO accessions: GSE63060, GSE63061, GSE249477, GSE282742, GSE136243, GSE150693, GSE285831 and GSE134578. The GEO accession pages are the primary source identifiers for GSE285831 and GSE134578. The repository does not redistribute individual-level records, controlled-access ADNI GO/2 data or serialized single-cell objects.

The public GitHub profile is https://github.com/JivonKiang. The repository release is limited to permitted code and aggregate source data; it is not a mirror of the complete local project directory.
