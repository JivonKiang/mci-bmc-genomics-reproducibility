# Data and code availability

Prepared: 3 August 2026

The public code and aggregate result tables for this study are available at https://github.com/JivonKiang/mci-bmc-genomics-reproducibility. The repository contains selected analysis scripts, aggregate figure-source tables, mapping audits and evidence-unit summaries. It is a public GitHub release, not a mirror of the complete local project directory.

All reused human datasets are identified by their original GEO accessions: GSE63060, GSE63061, GSE249477, GSE282742, GSE136243, GSE150693, GSE285831 and GSE134578. The GEO accession pages are the primary source identifiers for GSE285831 and GSE134578. The study does not redistribute individual-level controlled-access data, controlled-access ADNI GO/2 data or serialized single-cell objects.

Author profile: https://github.com/JivonKiang

The local submission package contains the upload manuscript, figures, source-data archive and full audit copy. The public repository contains the permitted selected release only. No DOI is assigned to the GitHub release at this time; the stable repository URL is used without a DOI claim.

Verified dataset-source references for GSE285831 and GSE134578 are recorded in `docs/REFERENCE_SOURCES_20260803.md`.
