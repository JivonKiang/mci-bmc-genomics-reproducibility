# Aggregate data reuse

The MIT License in `LICENSE` applies to original source code in this
repository. It does not automatically license the files under
`data/aggregate/`.

The aggregate CSV files are release artifacts derived from public GEO inputs
and the study workflow. Their reuse is subject to:

- the terms and attribution requirements of the original GEO records;
- copyright, database-rights and publication policies that apply to the source
  material;
- any applicable institutional or funder requirements; and
- the release boundary documented in `docs/PUBLIC_RELEASE_SCOPE.md`.

This repository does not redistribute controlled-access ADNI GO/2 data,
sample-level records, subject-level records, donor-level metadata or cell-level
objects. Do not reconstruct or infer individual-level records from the
aggregate tables.

When reusing an aggregate table, cite this repository and the relevant
original data source. Contact the maintainer through the public GitHub profile
before treating the tables as a separately redistributable dataset.
